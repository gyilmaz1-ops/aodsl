# AODSL VS Code Support

`.aodsl` syntax highlighting plus live AODSL language intelligence via `python -m aodsl lsp`.

Features:
- live Problems diagnostics
- completion for DSL keywords/actions/capabilities
- hover documentation
- document symbols / Outline
- go-to-definition for rule identifiers

Set `aodsl.pythonPath` to the Python executable where AODSL is installed.
